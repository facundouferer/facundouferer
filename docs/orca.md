**Orca: quizás la IDE definitiva para programar con agentes de IA**

Durante los últimos años la industria se dedicó a insertar inteligencia artificial dentro de los IDE: primero autocompletado, después chat y finalmente agentes capaces de modificar proyectos enteros. Orca propone invertir la ecuación. En lugar de construir un editor y agregarle agentes, construye el entorno alrededor de ellos. Técnicamente sus creadores prefieren llamarlo **ADE, Agent Development Environment**, y probablemente tengan razón: cuando Claude Code, Codex, Cursor CLI, Gemini, OpenCode y compañía empiezan a hacer buena parte del trabajo, mirar un archivo durante ocho horas deja de ser necesariamente el centro de la jornada.

La gran idea de Orca son los **worktrees paralelos**. Cada tarea puede vivir en su propio `git worktree`, con branch, archivos, terminales y agente independientes. Es posible darle el mismo bug a Claude Code, Codex y Cursor, dejarlos trabajar simultáneamente, comparar los tres diffs y quedarse con la mejor solución. No hay que hacer stash, cambiar de branch compulsivamente ni confiar en la memoria para recordar qué terminal estaba haciendo qué. Git, por una vez, termina ayudando a reducir la confusión en lugar de participar activamente en ella.

Pero Orca resulta especialmente interesante porque no termina cuando el agente acaba de escribir. Tiene un visor de diffs pensado para código generado por IA, permite comentar líneas y devolver todas las observaciones al agente para una nueva iteración, registra atribución entre cambios humanos y cambios de IA, integra navegador Chromium, terminales, GitHub, Linear y ejecución remota mediante SSH. Incluso existe una aplicación móvil para supervisar agentes que siguen trabajando en otra máquina. Ese conjunto convierte a Orca menos en “otro editor con IA” y más en una **cabina de control para un pequeño ejército de programadores sintéticos**, con todos los problemas laborales convenientemente sustituidos por rate limits.

Además, Orca es gratuito, open source bajo licencia MIT, funciona en macOS, Windows y Linux y permite utilizar las suscripciones de agentes que ya tenemos. El proyecto sigue además un ritmo de desarrollo notable: la release 1.4.199 apareció el 9 de septiembre de 2026. Experiencias independientes recientes destacan precisamente la organización de sesiones, los worktrees y el trabajo remoto como sus mayores ventajas.

**Cómo empezar con Orca**

1. Descargá Orca desde [onOrca.dev](http://onOrca.dev) para Windows, macOS o Linux. En macOS también puede instalarse con `brew install --cask stablyai/orca/orca`.
2. Instalá o configurá al menos un agente CLI, por ejemplo Claude Code o Codex. Orca no incluye el modelo: utiliza tus agentes y suscripciones existentes.
3. Abrí **Add Repo**, seleccioná un proyecto Git existente y creá un nuevo worktree con el botón `+`.
4. Elegí el agente que querés ejecutar. Para entender realmente Orca, creá dos o tres worktrees desde el mismo branch, enviá el mismo problema a agentes distintos y después compará sus diffs.
5. Antes de experimentar con repositorios importantes, revisá **Settings → Agents → Agent Permissions**. Orca puede iniciar agentes omitiendo confirmaciones de permisos; durante las primeras pruebas resulta sensato seleccionar **Manual** y aumentar la autonomía después.

Orca no será necesaria para quien todavía utiliza un único agente para tareas ocasionales. Pero cuando el desarrollo pasa de “pedirle algo a una IA” a **coordinar varias IAs que investigan, implementan, prueban y revisan en paralelo**, el IDE tradicional comienza a parecer una herramienta diseñada para una organización del trabajo anterior. Para ese nuevo escenario, Orca es hoy una de las propuestas más completas y convincentes.
