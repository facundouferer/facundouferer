## Design System

This site is built on **Organic**, the design system in `Organic/`.
The full contract is documented in [`DESIGN.md`](./DESIGN.md); agent-facing rules
live in [`AGENTS.md`](./AGENTS.md) §6.6 and [`CLAUDE.md`](./CLAUDE.md).

**All graphics used on this site must come from the Organic design system** —
not only components, but every visual artifact:

- **Components and layouts** — built from Organic classes (`.btn*`, `.card*`,
  `.tag*`, `.nav*`, `.container`, `.section`) and its tokens.
- **Illustrations, diagrams and inline SVG** — drawn with the Organic palette
  (`--color-accent` terracotta, `--color-accent-2` sage, the neutral ramp on the
  `--color-bg` cream ground), rounded geometry, and no sharp corners or
  hairline-only strokes.
- **Icons** — Lucide (https://lucide.dev) at `stroke-width: 2.75`. No other icon
  set.
- **Photographs** — wrapped in `.washed` with rounded edges, so they sit back
  into the warm page.
- **Article, project and course images** — same palette and rounded language;
  placeholders included.
- **Open Graph / social cards and presentation slides** — same palette and type
  pairing (Caprasimo display over Figtree body).

Do not introduce a second palette, a second display face, or a foreign icon set.
If a graphic cannot be expressed in Organic, extend the system in `Organic/` and
`DESIGN.md` rather than diverging in one file.

### System at a glance

| Role | Token | Value |
| --- | --- | --- |
| Ground | `--color-bg` | `#f5ead8` cream |
| Surface | `--color-surface` | `#ebddc5` sand |
| Text | `--color-text` | `#201e1d` |
| Accent | `--color-accent` | `#c67139` terracotta |
| Second accent | `--color-accent-2` | `#7a8a5e` sage |
| Display face | `--font-heading` | Caprasimo 400 |
| Body face | `--font-body` | Figtree 400/600/700 |
| Radius | `--radius-md` / `--radius-lg` | `16px` / `28px`, pills at `999px` |
