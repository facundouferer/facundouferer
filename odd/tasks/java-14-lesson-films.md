# Java lesson films for the remaining 14 lessons

Objective: Build 14 two-minute lesson films (`Opción B` in the style of `viaje-excepcion-java` / `CLAUDE.md` §Lesson films) for all 14 remaining Java lessons that currently lack an animation, replacing the uncommitted step-by-step stubs.
Branch `feat/java-14-lesson-films`, delivery `ask-on-risk`, runner `node --test` plus `npx astro check`.
Forecast: ~24,000 authored lines across 14 films (3 parallel waves of 5 + 5 + 4 delegated writers, committed in work-unit commits per film).

## Specs

- S1. Film for lesson 5 (`/cursos/java/05-metodos-y-funciones`, file `05-metodos-y-funciones.es.md`/`.en.md`, `order: 5`), slug `metodos-funciones-java`: follows a call from `main` pushing a stack frame onto the Call Stack, pass-by-value copy (modifying the parameter does not alter caller's variable), `return` popping the frame back with the result.
- S2. Film for lesson 6 (`/cursos/java/23-algoritmia-verificacion-y-complejidad`, file `23-algoritmia-verificacion-y-complejidad.es.md`/`.en.md`, `order: 6`), slug `algoritmia-complejidad-java`: follows a precondition check, a loop invariant, and compares linear search $O(n)$ steps against binary search $O(\log n)$ halving the search space on the same sorted array.
- S3. Film for lesson 7 (`/cursos/java/06-introduccion-y-pilares-poo`, file `06-introduccion-y-pilares-poo.es.md`/`.en.md`, `order: 7`), slug `introduccion-pilares-poo-java`: follows how scattered procedural variables and functions become a cohesive object combining state and behavior around the four OOP pillars (abstraction, encapsulation, inheritance, polymorphism).
- S4. Film for lesson 8 (`/cursos/java/07-fundamentos-poo-clases-y-objetos`, file `07-fundamentos-poo-clases-y-objetos.es.md`/`.en.md`, `order: 8`), slug `clases-objetos-java`: follows a class blueprint instantiating two independent objects on the heap with `new`, references on the stack, attribute mutation on one vs reference aliasing when two variables point to the same object.
- S5. Film for lesson 9 (`/cursos/java/07-constructores-y-encapsulamiento`, file `08-constructores-y-encapsulamiento.es.md`/`.en.md`, `order: 9`), slug `constructores-encapsulamiento-java`: follows object construction with `this`, the compiler blocking direct access to a `private` field (magenta), and a setter validating the invariant before updating the state (violet).
- S6. Film for lesson 10 (`/cursos/java/09-arrays-de-objetos`, file `09-arrays-de-objetos.es.md`/`.en.md`, `order: 10`), slug `arrays-objetos-java`: follows `new Persona[3]` creating an array of `null` references (and the `NullPointerException` trap on an empty slot in magenta), populating slots with `new Persona(...)`, traversing the array with a `null` check, and aliasing `equipo[2] = equipo[0]` (class name taken from the lesson, see L4).
- S7. Film for lesson 16 (`/cursos/java/11-tad-listas-estaticas-y-dinamicas`, file `13-tad-listas-estaticas-y-dinamicas.es.md`/`.en.md`, `order: 16`), slug `tad-listas-java`: follows node insertion and pointer rewiring (` cabeza -> nodo -> siguiente `) in a singly linked list vs shifting elements in a contiguous static list.
- S8. Film for lesson 17 (`/cursos/java/12-tad-pilas-y-colas`, file `14-tad-pilas-y-colas.es.md`/`.en.md`, `order: 17`), slug `tad-pilas-colas-java`: follows elements entering and leaving a LIFO Stack (`push`/`pop` at `tope`) vs a FIFO Queue (`encolar`/`desencolar` between `frente` and `fondo`).
- S9. Film for lesson 18 (`/cursos/java/15-tad-arboles-binarios-y-busqueda`, file `17-tad-arboles-binarios-y-busqueda.es.md`/`.en.md`, `order: 18`), slug `arboles-binarios-java`: follows a Binary Search Tree (BST) insertion/search comparing keys left (`<`) and right (`>`), discarding half the tree at each level, and in-order traversal visiting keys in sorted order.
- S10. Film for lesson 19 (`/cursos/java/26-arboles-n-arios-y-representacion-con-vectores`, file `26-arboles-n-arios-y-representacion-con-vectores.es.md`/`.en.md`, `order: 19`), slug `arboles-n-arios-java`: follows an N-ary tree transformed into first-child / next-sibling (`primerHijo` / `siguienteHermano`) links and stored in parallel parent-index vectors with validated indices.
- S11. Film for lesson 20 (`/cursos/java/16-grafos-representacion-y-algoritmos`, file `18-grafos-representacion-y-algoritmos.es.md`/`.en.md`, `order: 20`), slug `grafos-java`: follows a graph represented as an adjacency list, a BFS wave exploring layer by layer with a queue, and Dijkstra relaxing edge weights to find the shortest path.
- S12. Film for lesson 21 (`/cursos/java/17-archivos-persistencia-y-empaquetado-jar`, file `19-archivos-persistencia-y-empaquetado-jar.es.md`/`.en.md`, `order: 21`), slug `archivos-jar-java`: follows an object in volatile Heap memory written through `BufferedWriter` / `try-with-resources` to a persistent file on disk and packaged with a `MANIFEST.MF` entry point into an executable `.jar`.
- S13. Film for lesson 22 (`/cursos/java/19-programacion-concurrente-hilos-y-pools`, file `20-programacion-concurrente-hilos-y-pools.es.md`/`.en.md`, `order: 22`), slug `concurrencia-hilos-java`: follows two threads racing on a shared counter (lost update in magenta), a `synchronized` lock serializing access so both increments persist (violet), and a thread pool (`ExecutorService`) dispatching tasks.
- S14. Film for lesson 23 (`/cursos/java/19-acceso-a-bases-de-datos-jdbc`, file `21-acceso-a-bases-de-datos-jdbc.es.md`/`.en.md`, `order: 23`), slug `jdbc-java`: follows a SQL injection risk with string concatenation (magenta), a `PreparedStatement` binding `?` parameters safely through the JDBC `Connection`, and a transaction (`setAutoCommit(false)` / `commit()` / `rollback()`) keeping the database consistent.
- S15. Every film follows `CLAUDE.md` §Lesson films and `AGENTS.md` §Curriculum sequencing: study the lesson first (using only concepts up to that lesson's `order`), one continuous story on one persistent motion canvas (`data-scene="journey" data-motion`, `viewBox="0 0 1280 720"`), 6 chapters, 8 motion steps, 90 to 120 seconds total duration in both `es` and `en`, `--xj-*` palette token block (with raw hex only inside that token block), fixed editor on the left (at most 20 lines, localized identifiers/strings) and isometric 2.5D system on the right, neutral Latin American Spanish (no voseo) + English captions (1 to 3 per step, 15–120 chars each), Organic SVG thumbnail in `public/img/animations/<slug>.svg`, and dedicated test `tests/animation-<slug>.test.mjs`.
